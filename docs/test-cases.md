## 관찰·리뷰 및 구현 연결

- TC-LGN-001은 2026-11-18 Chromium PC(1280×720)·Pixel 7 에뮬레이션에서 직접 확인했다. 두 환경 모두 HTTP 200, Username(text)·Password(password)·Login(submit)을 확인했다. 사용자 진행 승인에 따라 P0 샘플로 구현한다. 후속 TC는 관찰·리뷰 대기다.
- P0 리뷰 대상은 TC-LGN-001이다. 후속 TC는 각 Phase에서 관찰과 리뷰를 완료한다.
- 핵심 구매 경로에는 @smoke와 @regression을 적용하고, 추가 설계 검증과 결함 시연에는 @regression을 적용한다.
- 자동 후보 11개와 수동 후보 1개다. 데이터 반복 및 환경별 실제 실행 건수는 별도 집계한다.
- 재현한 결함은 trace와 known-issues에 연결한다. test.fail()은 확인된 결함에 적용한다.
- 사용자 리뷰에서 추가한 TC는 리뷰 추가로 표시한다.
### P1 관찰 결과

정상 공개 계정으로 Chromium PC(1280×720)와 Pixel 7 에뮬레이션에서 각각 새 컨텍스트로 로그인했다. 두 환경 모두 /inventory.html로 이동했고 Products 제목과 6개 상품을 확인했다. TC-LGN-002는 URL·제목·목록 표시를 검증한다. 사용자 P1 진행 승인에 따라 해당 TC를 구현하며, 다른 기능 TC는 관찰·리뷰 대기다. 비밀번호는 로컬 .env에서만 읽는다.
