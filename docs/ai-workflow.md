관찰·실행·시간 비교는 수행 후 실제 기록으로 추가한다. 공개 지표는 데모 결과를 근거로 작성한다.
## P0 환경 준비 · 2026-11-18

- AI 작업 — 프로젝트 내부 npm·Chromium 설치, 설정·Page Object·샘플 작성, 실제 로그인 화면 관찰과 실행 검증.
- 사용자 판단 — 프로젝트 내부 설치 승인, Chromium PC·모바일 실행 승인, P0 진행 승인.
- TC — TC-LGN-001을 PC 1280×720과 Pixel 7 에뮬레이션에서 확인하고 기대 결과 확정. 신규 리뷰 추가 TC는 0개이며 후속 TC는 리뷰 대기.
- 실행 결과 — 동일 TC를 두 환경에서 실행해 2건 통과. TypeScript 검사 통과.
- 실패 분석 — 최초 2건 실패는 테스트 설정 결함. trace에서 data-testid로 검색하는 호출과 사이트의 data-test 속성을 확인했다. testIdAttribute를 data-test로 수정한 뒤 통과했다. 재시도 설정으로 처리하지 않았다.
- 소요 시간 — 작업 시간은 사전 측정하지 않았으므로 미기록. 최종 테스트 실행 도구가 보고한 시간은 990ms이며 수동 대비 절감 지표로 사용하지 않는다.
- 설치 위치 — npm은 .tools/npm, 패키지는 node_modules, npm 캐시는 .cache/npm, 브라우저는 .cache/ms-playwright. 기존 시스템 Node.js 24.22.3을 사용한다.
## P1 정상 로그인

- AI 작업 — PC·모바일 실제 로그인 관찰, TC-LGN-002 기대 결과 확정, 로그인 Page Object 확장, InventoryPage 및 독립 로그인 테스트 작성.
- 사용자 판단 — P1 진행 승인. 로그인 예외와 잠금 계정은 제출 범위에서 제외.
- 사용자 신규 리뷰 추가 TC — 0개.
- 관찰 결과 — 두 환경 모두 정상 로그인 후 /inventory.html과 Products 제목, 상품 목록 표시 확인.
- 실행 결과 — P0·P1 TC 2개를 2개 환경에서 실행해 4건 통과. TypeScript 검사 통과. 신규 실패와 재시도 없음.
- 소요 시간 — 총 작업 시간은 측정하지 않음. 최종 테스트 실행 도구 보고 시간 1.9초.
- 비밀값 — 공개 사이트에서 제공하는 비밀번호를 로컬 .env에 저장해 실행 시 읽음. Git 제외 확인.
## P2 관찰·TC 리뷰 준비 · 2026-11-18

- AI 작업 — PC·모바일에서 상품 상세부터 주문 완료까지 직접 관찰. 필수 입력 3개는 각각 독립 컨텍스트로 확인. 7개 TC의 기대 결과 구체화.
- 사용자 판단 — P2 진행 승인. 구체화된 TC는 리뷰 대기.
- 사용자 신규 리뷰 추가 TC — 현재 0개. 후속 리뷰에서 갱신.
- 관찰 결과 — 두 환경의 구매 동선과 오류 메시지가 일치. 선택한 두 상품 소계 $39.98, 세금 $3.20, 총액 $43.18 확인.
- 금액 판단 — 관찰만으로 일반 세율·반올림 요구사항을 확정하지 않고 해당 상품 조합의 기준금액과 합계 검증을 제안.
- 소요 시간 — 관찰 실행 도구 보고 약 6초. 총 설계·검토 시간과 수동 대비 절감은 측정하지 않음.
- 검증 상태 — 관찰 성공, P2 테스트 구현·실행 검증은 TC 리뷰 후 진행.
## P2 구현 및 검증

- AI 작업 — InventoryPage 확장, CartPage·CheckoutPage·로그인 fixture 작성, 상품·주문 데이터 분리, 승인된 P2 TC 7개 구현.
- 사용자 판단 — 관찰 결과와 7개 TC 검토 후 구현 승인. 신규 리뷰 추가 TC는 0개.
- 금액 검증 — 관찰한 두 상품의 기준금액, 화면 상품가 합계와 소계, 소계+세금과 총액을 센트 정수로 검증한다. 세율과 반올림 일반 규칙은 추가 근거 확인 대상으로 유지한다.
- 최초 실행 — 18건 통과·4건 실패. trace에서 상세 진입 요소가 link가 아닌 button 역할임을 확인했다.
- 두 번째 실행 — 역할 수정 후 18건 통과·4건 실패. 이미지와 상품명 버튼에 동일 접근성 이름이 있어 strict mode 위반이 발생했다. 상품명 텍스트를 포함하는 버튼으로 범위를 한정했다.
- 분류 — 두 원인은 테스트 로케이터 결함으로 분류했다. 근거 trace는 .cache/p2-initial-failures 및 .cache/p2-role-ambiguity에 보관했다. 사이트 결함으로 기록하지 않는다.
- 최종 결과 — 22건 통과, 재시도 0회, TypeScript 검사 통과. 전체 TC ID 9개, 데이터 반복 적용 시 환경당 11건, 두 환경 합계 22건이다.
- 소요 시간 — 총 작업 시간은 미측정. 최종 전체 테스트 도구 보고 시간 8.2초이며 수동 대비 절감률 계산에는 사용하지 않는다.
